Making the token

  1. In Home Assistant, go to Settings > People > Users and add a user just for Claude, for example Claude. Turn on Administrator: logs, traces, integrations and automation configs are only open to administrators.
  2. Log in to Home Assistant once as that user, open its profile (bottom left), the Security tab, and under Long-lived access tokens choose Create token.
  3. Copy the token (Home Assistant shows it only once), paste it above and press Save.
A separate user means everything Claude does shows up in Home Assistant's logbook under that name, and you can revoke it there at any time.

  1. On claude.ai, open Customize > Connectors, choose + Add, then Add custom connector.
  2. Name it HomeClaude and paste the URL. Under Authentication choose No sign in.
  3. Under Request headers add the header above (name Authorization, value Bearer …), then Add. Claude Desktop and the phone app use the same connector.
If a Claude app has no place for headers, the URL /mcp/<token> also works (the token is then part of the address).
